## 📌 Project Overview

**Swift Wheels** is a console-based Rent a Car Management System developed using the **C Programming Language** as part of the IN1101 Programming Fundamentals module.

The system is designed to automate vehicle rental operations by managing customers, vehicles, rental bookings, invoices, payments, and administrative reports through a structured menu-driven interface.

The project demonstrates fundamental programming concepts including **structures, arrays, functions, modular programming, searching, data management, and business logic implementation**.

---

# ✨ Key Features

## 👤 Customer Management

* Add new customers
* View all customer records
* Search customers by ID
* Update customer information
* Remove customer records
* Maintain customer activity status

---

## 🚘 Vehicle Management

* Add new vehicles to fleet
* View all registered vehicles
* View available vehicles
* Search vehicles by ID
* Update vehicle rental rates
* Decommission unavailable vehicles
* Track vehicle availability status

---

## 📅 Rental & Booking Management

* Create vehicle pre-bookings
* Activate vehicle pickup
* Process vehicle returns
* Calculate rental duration
* Track rental status:

  * Pre-booked
  * Active
  * Returned
  * Cancelled

---

## 💰 Billing & Payment System

* Generate rental invoices
* Calculate rental charges
* Calculate additional kilometer charges
* Manage advance payments
* Apply late fees
* Track outstanding balances
* Generate revenue summaries

---

## 📊 Reports & Administration

* System dashboard
* Vehicle rental frequency reports
* Customer rental history search
* Admin activity logs
* Rental statistics

# ▶️ How to Run

## Requirements

* GCC Compiler
* Code Editor (VS Code recommended)

## Compile

```bash
gcc main.c -o swift_wheels
```

## Run

Windows:

```bash
swift_wheels.exe
```

Linux / Mac:

```bash
./swift_wheels
```
